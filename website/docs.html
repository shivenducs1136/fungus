Getting Started

AI-assisted software development generates valuable architectural reasoning during implementation. The final code captures what was built, but not why a solution was chosen, the constraints discovered, or the tradeoffs considered.

Fungus preserves that reasoning and links it directly to source code through Git history, ensuring it remains accessible to future developers and AI agents.

The goal is to preserve implementation rationale so future developers and future AI agents can make informed decisions without repeating past investigations.

Architecture

The Fungus ecosystem consists of two primary organisms:

  1. Knowledge Server: A robust FastAPI-based service providing knowledge storage, context retrieval, hash generation, and persistence.
  2. MCP Server: A lightweight client-side standalone executable that handles Git operations and interacts with the Knowledge Server to save and retrieve context over stdio.

Installation

The MCP server is packaged as a single fungus-mcp.exe file (~20 MB) so users need no Python installation.

1. Quick Install (Windows Release)

Open PowerShell in your preferred tooling directory and run this one-liner to download the executable and construct the mcp.json configuration file automatically:

iwr https://github.com/shivenducs1136/fungus/releases/download/v1.0.0/fungus-mcp.exe -OutFile fungus-mcp.exe; $j = (iwr https://github.com/shivenducs1136/fungus/releases/download/v1.0.0/mcp_distribution.json).Content | ConvertFrom-Json; $j.servers.'fungus-knowledge'.command = "$PWD\fungus-mcp.exe"; $j | ConvertTo-Json -Depth 5 | Out-File mcp.json -Encoding utf8

This command dynamically injects the absolute path of the downloaded executable into your mcp.json file.

2. Building From Source

If you prefer to build the executable yourself from the latest source code:

git clone https://github.com/shivenducs1136/fungus.git
cd fungus
.\build\build_exe.ps1

This installs PyInstaller into the active virtual environment and produces dist\fungus-mcp.exe.

Usage & MCP Configuration

Once you have the mcp.json file ready, configure your AI agent to use it. For Claude Desktop, simply append the servers block from mcp.json to your claude_desktop_config.json.

For Cursor and VS Code, provide the path to your mcp.json or configure it directly in their respective UI settings.
